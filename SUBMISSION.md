Title: Agent Permission Check

Notes / Description:
Built a reusable human-controlled agent permission ticket. A controller freezes a capability registry and global boundary, one designated agent declares a proposed action, target, and reason, and GenLayer validators classify capability fit and scope. The classification never grants access: only the controller can approve or deny, can revoke before completion, and the agent records a bounded execution attestation. No action or payment is automated.
